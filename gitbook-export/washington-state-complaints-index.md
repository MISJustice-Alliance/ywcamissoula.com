# Washington State Complaints Index

This index collects MISJustice Alliance pages about Washington professional-oversight complaints, a police-accountability complaint, and a court-record privacy motion. A complaint asks for review; listing it here does not establish that an agency investigated, agreed with its allegations, or made a disciplinary finding. Each page identifies its own available records and limits.
