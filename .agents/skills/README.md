# MISJustice Alliance skill library — proposed

These are task-triggered workflows, not persistent agents or grants of tool access. Skills are not automatically followed through links. From a trusted repository session, load only relevant SKILL.md; read each required policy explicitly. No subagent is required: do drafting, then a separate review pass sequentially if an independent reviewer is unavailable, disclosing that limitation.

Do not flatten the account into ‘both sides disagree.’ Fairness requires material completeness and evidence-weighted treatment, not equal credibility or a manufactured midpoint. Supported wrongdoing must not be sanitized; material contrary evidence must change the thesis when warranted. Advocacy sets purpose, not predetermined findings or expanded permissions.

The current main-branch AGENTS.md and CLAUDE.md are historical Notion migration guides; their examples are not standing permissions. The proposed `EDITORIAL_STYLE.md` from the separate instruction refactor is NOT applied at the inspected revision. Public-facing editorial readiness in this library is conditional on approving/adding it (or resolving an equivalent authoritative policy); do not claim compliance with an absent file. Existing publisher policy at `gitbook-export/overview/about-this-site-publisher-and-corrections.md` remains operative.
